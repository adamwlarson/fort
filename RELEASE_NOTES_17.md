# Fort 17 — Build from shared supplies

At a castle project's sign, hold E to supply and build without reopening the architect menu. The host takes only the outstanding recipe cost, using shared stock first and your carried materials for any shortfall. Keep holding E to perform construction after funding. If supplies run out, construction waits until you gather or restock.

This applies to castle wings (including the Grand stairwell), curtain-wall projects, remodeling and research projects. It does not change the separate B-menu defense construction system, which already pays its placement cost from shared stock.

The K-menu shared-stock button remains available. Placement and clearance requirements, costs, work requirements and cancellation rules are unchanged. Cancellation returns eligible unused supplies to shared stock, as before.

All players must use Fort 17. Fort 14–16 saves remain supported; the save schema remains 2. Earlier packaged versions are preserved.
